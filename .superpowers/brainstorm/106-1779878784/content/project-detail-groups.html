Key interactions

  • Click group header — collapse/expand rooms
  • ⋯ menu on group — rename, add room to group, delete group (rooms become ungrouped)
  • + Add group — creates empty group, then drag rooms in or use ⋯ menu
  • + Add room — creates room in selected group (or ungrouped if none)
  • Drag rooms — reorder within group or move between groups (uses existing @dnd-kit)
