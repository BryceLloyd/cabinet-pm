Behavior

  • View toggle: Gantt | Calendar | 2 Week | Events — "2 Week" is the new option
  • Navigation: ‹/› arrows shift by 1 week at a time. "Today" button jumps back to current fortnight.
  • Today highlight: Green border + "TODAY" badge on current day
  • Weekends: Muted background to de-emphasize
  • Events: Color-coded by event type (left border + tinted background). Click → opens event slide panel.
  • Click empty day: Opens quick-add event modal (same as existing calendar behavior)
  • Mobile: Stacks to a single-column list of days with events underneath each
